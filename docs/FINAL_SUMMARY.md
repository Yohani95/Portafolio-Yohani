### **2. Deploy en Vercel** 🌐

#### **Opción A: Desde Vercel Dashboard** (Recomendado)

1. Ve a https://vercel.com/new
2. Importa tu repositorio `Yohani95/portfolio-nx`
3. Configurar:

   - **Build Command**: `npx nx build portfolio-web --configuration=production`
   - **Output Directory**: `dist/apps/portfolio-web/browser`
   - **Install Command**: `npm install`

4. Agregar variables de entorno:

   ```
   NG_APP_GITHUB_TOKEN = ghp_tu_token_aqui
   NG_APP_GITHUB_USERNAME = Yohani95
   NG_APP_BASE_URL = https://[tu-proyecto].vercel.app
   ```

5. Click **"Deploy"**

#### **Opción B: Desde CLI**

```bash
# Instalar Vercel CLI
npm install -g vercel

# Login
vercel login

# Deploy
vercel --prod
```

### **3. Configurar GitHub Secrets** 🔐

Para GitHub Actions:

1. Ve a tu repo → Settings → Secrets and variables → Actions
2. Agrega:
   - `VERCEL_TOKEN` = (obtener de https://vercel.com/account/tokens)
   - `VERCEL_ORG_ID` = (Settings → General en Vercel)
   - `VERCEL_PROJECT_ID` = (Project Settings → General)
   - `GITHUB_USERNAME` = `Yohani95`
   - `BASE_URL` = tu URL de Vercel

## 🎓 **Lecciones Aprendidas**

### **Técnicas**

1. Node.js v21 no es compatible con Angular 20 → Usar v20 o v22+
2. SSR requiere guards de `isPlatformBrowser` para acceso al DOM
3. Cache en memoria es suficiente para GitHub API
4. Non-buildable libraries simplifican el setup de Nx
5. Signals > NgRx para proyectos pequeños/medianos

### **Best Practices**

1. Conventional Commits mejoran el historial
2. Tests primero = menos bugs después
3. Documentación temprana ahorra tiempo
4. SSR mejora SEO dramáticamente
5. Dark mode es esperado en 2025
